# GoodbyeDPI-Turkey-GUI

A modern, lightweight WinUI 3 desktop client for GoodbyeDPI with pre-configured Turkish ISP presets.

---

## Download 

1. Go to the [Releases](https://github.com/zarkido/GoodbyeDPI-Turkey-GUI/releases) section.
2. Download the latest `GoodByDpi.exe`.
3. Run as Administrator, select your ISP preset, and click Start.
